# Math Practice

Offline-first daily math practice PWA.

## Install (iPhone)

1. Open the GitHub Pages site in **Safari**.
2. Tap **Share → Add to Home Screen**.
3. Use it offline (no data needed on the road).

## Optional progress sync

Progress stays on the phone. If `js/config.js` has an `endpointUrl` (Apps Script web app), a totals summary is POSTed when online. Leave `endpointUrl` empty to keep sync off.
